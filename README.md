# Abhignan Vajjala — Research Portfolio

A React, TypeScript, and Vite portfolio for undergraduate computational biology projects and scientific software. The design uses Tailwind CSS with custom CSS, native scroll and reveal effects, Lucide icons, and the original scientific illustrations.

## Run locally

Requires Node.js 20+ and npm.

```bash
npm ci
npm run dev
```

Open the address printed by Vite. To check the production build:

```bash
npm run build
npm test
npm run preview
```

## Deploy to Vercel

1. Commit the portfolio files and push them to the GitHub repository’s `main` branch. Then import that repository into Vercel.
2. Select the **Vite** framework preset. Use `npm run build` as the build command and `dist` as the output directory.
3. Deploy. The Vite build prerenders the homepage and all project pages. Vercel serves these files at their extensionless URLs, and React hydrates them for client navigation.

No environment variables or backend services are required.

## Update content

All personal links, projects, conference statuses, research interests, and toolkit evidence links are in `src/data.ts`. The two model investigations retain their demo URLs. Bioinformatics Agent Skills has a compact software entry and a project route.

`src/App.tsx` contains the reusable sections, cards, navigation, and project routes. `src/HelixScene.tsx` draws the scroll-responsive DNA scene; `src/Visuals.tsx` contains the project illustrations. `src/style.css` and `src/redesign.css` contain the responsive visual system. `public/` contains the favicon and social preview image.

`src/seo.ts` defines page metadata for client navigation and for the static HTML generated by `prerender.tsx`.

The helix and project-card illustrations are explanatory. Project figures use a mapped predicted structure, recomputed ranking sensitivity and preserved metabolic outputs. Each figure includes provenance and interpretation. Project findings and conference status labels should be updated only when supported by records.

## Verify the scientific presentation

The numerical audit is independent of the frontend build. It checks frozen source hashes, score arithmetic, shortlist membership, weight sensitivity and metabolic output parsing. Rendering dependencies are pinned separately. See [reproducibility/README.md](reproducibility/README.md) for execution commands, exact source revisions, calculations performed and unresolved model/benchmark inputs.

```bash
python reproducibility/analyze.py --check
python -m unittest discover -s tests -p "test_*.py"
```

The original metabolic solver runs and experimental interaction validation remain incomplete. Frontend tests verify the presentation and routes.
